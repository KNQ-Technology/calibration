# 相机标定流程与产物说明

> 本文档整理自 2026-07-09 的 Claude Code 会话，涵盖项目的完整标定操作流程、最终产物清单及注意事项。

## 项目简介

本项目是 MCS 系统的一部分，用于足球/训练场景的单目相机标定。核心功能是建立坐标变换链：

```
像素坐标 → 去畸变 → 单应变换 → 球场物理坐标（cm）
```

## 程序入口

| 命令 | 说明 |
|---|---|
| `python measure_marker_position.py` | 主流程：标定 + 标志物测量（OpenCV 弹窗标注 + 命令行交互） |
| `python annotation_client.py` | 带完整界面的 tkinter 标注客户端，生成与主流程相同格式的 JSON 缓存 |

环境要求：Python 3.10，`pip install -r requirements.txt`。

## 完整标定操作流程

### 准备阶段

1. 配置根目录 `config.yaml`：
   - `video_name` / `CAMERA_NAME`：输入视频与相机名（决定存储目录名）
   - `config`：球场规格类名（对应 `soccer.py` 中的配置类，如 `QingYuanConfiguration`）
   - `GROUP_CONFIGS` / `PAIR_CONFIGS`：组内 / 组间距离测量配置
   - `jac`（`2-point`/`3-point` 差分）、`reprojection_eps`（重投影误差阈值）、`enable_orientation`（保定向判定）：畸变优化器参数
2. 确认视频文件位于 `dir_path` 指定目录下。

### 相机标定阶段（构造 `Camera` 时自动触发，缺哪步补哪步）

1. **关键点标注** → `keypoints.json`：在视频帧上标注球场关键点，编号需与球场配置类 `vertices` 对应
2. **横向直线标注** → `manual_horizontal.json`：标注画面中实际应为直线的横向线（畸变标定用）
3. **纵向直线标注** → `manual_vertical.json`
4. **计算畸变参数** → `distortion_params.json`：Brown-Conrady 五参数模型（k1,k2,k3,p1,p2），LM 优化，以"直线去畸变后变直"为约束，无需人工操作
5. **计算单应矩阵**：关键点先去畸变，再与球场物理坐标求单应
6. **计算视野（FOV）与可见网格**，自动生成验证图
7. **训练区域标定** → `train_area.json`：先在视频画面标注自定义点（可选，按 's' 保存空组可跳过），再在俯视图上框选区域
8. 保存 `camera_info.json`

### 标志物测量阶段

9. **标注标志物** → `store/manual/{CAMERA_NAME}/markers.json`：每组代表一类标志物，按 **'n'** 切换下一组，按 **'s'** 保存；已有缓存时命令行会询问是否复用
10. **坐标转换**：像素 → 球场物理坐标
11. **计算距离并输出**：组内相邻点距离（线性/环形）、组间重心/最近点距离，生成报告与可视化

## 最终产物

### 1. 相机标定参数（`store/{CAMERA_NAME}/`）—— 核心产物，供 MCS 复用

| 文件 | 内容 |
|---|---|
| `camera_info.json` | 单应矩阵、相机位置、视野范围、可见网格等综合信息 |
| `distortion_params.json` | 镜头畸变参数（k1, k2, k3, p1, p2） |
| `keypoints.json` | 球场关键点标注 |
| `manual_horizontal.json` / `manual_vertical.json` | 畸变标定用直线标注 |
| `train_area.json` | 训练区域边界 |

### 2. 标志物测量结果（`store/manual/{CAMERA_NAME}/`）

| 文件 | 内容 |
|---|---|
| `measurement_report.txt` | 测量报告：组内间距、组间重心/最近点距离（单位：米） |
| `coordinates.json` | 各标志物的像素坐标与球场物理坐标 |
| `visualization.jpg` | 球场俯视图（含距离标注） |
| `markers.json` | 标志物标注缓存 |

### 3. 图片产物（以 机位1_30s 为例，共 10 张）

**标定目录 `store/机位1_30s/`（7 张）**

| # | 文件 | 用途 |
|---|---|---|
| 1 | `keypoints_annotated.png` | 关键点标注记录 |
| 2 | `manual_horizontal_annotated.png` | 横向直线标注记录 |
| 3 | `manual_vertical_annotated.png` | 纵向直线标注记录 |
| 4 | `机位1_30s_return.jpg` | 关键点反投影回视频画面（验证标定精度） |

## 注意事项

- **缓存机制**：所有标注结果均缓存于 `store/` 下，重跑时已有文件的步骤直接跳过；想重做某步，删除对应 JSON 即可。
- **对比实验**：修改 `jac` / `enable_orientation` 等优化参数前，必须删除 `store/{CAMERA_NAME}/distortion_params.json`，否则程序会直接读旧结果，新参数不生效。
- **单位约定**：球场物理坐标全程使用 **cm**，测量报告展示时转换为**米**。
- **中文路径**：Windows 下 `cv2.imwrite`/`cv2.imread` 无法处理中文路径，需使用 `area.py` 中的 `imwritex`。
- **标定新视频**：修改 `config.yaml` 后，整套标定流程从头走一遍。
