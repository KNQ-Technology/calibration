场地标定工具｜四条边线标定测试版（Windows 64 位）

本包是独立测试版，只在解压后的目录内读写标注与结果；没有修改或连接正式项目。
本包自带 Windows Python 运行环境，不需要另行安装 Python。

使用方法
1. 完整解压压缩包到可写文件夹，双击 Start-Calibration.cmd。
2. 在“项目设置”中选择视频、填写测试机位名和选择正确的场地配置，点“应用并保存配置”。
3. 直接进入新增的第 5 步“四条边线标定”。若选择四边模式，可跳过旧关键点、横向直线和纵向直线；若要使用旧模式，仍按原有步骤标注。
4. 依次选择“上边线 y=0、右端线 x=长度、下边线 y=宽度、左端线 x=0”，每条线在原视频画面中点两个位置。名称按球场坐标定义，不一定对应屏幕的上、右、下、左。可点“查看场地图编号与方向”核对。
5. 看不清、需要凭其他线索推定的边线勾选“推定”。点“检查并预览四边范围”；检查白色四边轮廓和黄色球场线投影是否与可见中线、禁区线一致，然后点“保存本步”。标定写入 store\<机位名>\field_boundary.json。
6. 继续训练区域、器材分组和“保存并运行测量”。有有效四边标定时，主流程直接采用四线交点计算场地映射，并以映射后的场地范围筛选场内目标；不再调用旧关键点或旧畸变参数。camera_info.json 中可查看 field_calibration_mode=four_edges。
7. 若希望恢复旧模式，取消“启用四边标定（关闭后使用旧模式）”，再次点“保存本步”。未创建 field_boundary.json 时也直接沿用旧模式。

注意
- 四条边线与场地预设的方向必须对应。预览画出的轮廓只是几何一致性检查，不能证明不可见边线的真实位置；推定线的精度取决于人工判断。
- 四边测试模式直接在原视频画面上做透视映射，不使用旧畸变校正缓存。画面存在镜头弯曲时，直线近似可能仍有误差。旧模式的畸变校正流程保持不变。
- 边线标定文件与机位、场地长宽或视频画面尺寸不匹配时，程序会明确报错，不会悄悄套用旧结果。请在测试版中重新标定。
- 换视频后即使分辨率相同，也要确认机位和构图未变；程序会提示标定来源不同，但无法自动证明两段画面完全一致。
- 请在解压后的可写目录中使用，不要直接从压缩包运行。包内 store 为空，不含旧项目的视频或历史标注。
- 如需测试旧标注，请先备份并仅复制所需的 store 子目录到这个测试包。不要让测试版和正式项目共用同一个 store 路径。
- 当前是测试版，尚未在 Windows 实机做界面验收；请先用非生产素材验证结果，再决定是否应用到正式项目。
